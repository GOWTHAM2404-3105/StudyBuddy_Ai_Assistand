The Academic Challenge & Problem Statement

Why traditional study methods and generic cloud chatbots fall short for university students.

Information Overload

Students manage hundreds of pages of unindexed lecture slides, PDFs, and textbook chapters with no direct semantic search capability.

AI Hallucinations & Cloud Leakage

Commercial cloud chatbots hallucinate facts without citations and expose private student assignment data to external corporate servers.

Late Academic Setbacks

Students discover conceptual gaps only after midterm exam failures, lacking early-warning forecasting models to calibrate study hours.

Speaker Notes: We identified three critical gaps in modern college studying: information overload in static PDFs, lack of document citations and privacy issues with cloud LLMs, and the absence of data-driven early warning systems before final examinations.

Project Objectives & System Capabilities

Core functional pillars engineered into the StudyBuddy architecture.

1. Privacy-Preserving AI Study Chatbot

Runs locally via Ollama without cloud API subscriptions. Acts as an empathetic academic tutor explaining concepts step-by-step.

2. PDF Notes Assistant with Semantic RAG

Extracts text via PyMuPDF, performs cosine similarity retrieval over embeddings, and cites precise page numbers with anti-hallucination guards.

3. Automated 4-Choice MCQ Quiz Generator

Synthesizes topic/document-grounded questions with separated correct answers, auto-evaluation, and conceptual explanations.

4. ML Early Academic Performance Forecasting

Trained on the UCI Student Performance benchmark to forecast final grade (G3) using study hours, class failures, and attendance patterns.

5. Transparent Rule-Based Recommendations

Analyzes diagnostic quiz attempts per topic to prescribe targeted revision pathways, retry quizzes, and matched lecture notes.

6. Interactive Analytics Dashboard

Chart.js-powered visual telemetry showing subject mastery distribution and score progression over time.

Speaker Notes: StudyBuddy is designed across six integrated modules: authentic local LLM chat, verified document RAG with page citations, automated MCQ testing, early machine learning grade prediction, transparent recommendations, and live visual analytics.

Module 1 & 2: Security & AI Study Chatbot

Protecting student data and delivering pedagogical, multi-turn AI instruction.

Authentication & User Isolation

  • PBKDF2:SHA256 cryptographic password hashing via Werkzeug.
  • Session-based access control with custom @login_required decorator.
  • Strict database-level multi-tenancy: One student cannot read or query another student's uploaded notes, quizzes, or grade forecasts.

AI Study Chatbot Engine

  • Instruction-following system prompting enforcing step-by-step concept derivations.
  • Multi-turn memory: Retains the student's conversation history in SQLite for contextual continuity.
  • Graceful resilience: Detects Ollama state and delivers informative setup guidance without crashes.
Speaker Notes: In Module 1, security is guaranteed through PBKDF2 hashing and user-isolated database constraints. In Module 2, the AI Chatbot maintains conversation history and uses pedagogical prompting to break complex math and code into digestible steps.

Module 3: PDF Notes Assistant (Semantic RAG)

Retrieval-Augmented Generation that eliminates hallucination through precise page citations.

Step 1: Ingestion & Page Tracking

PyMuPDF (pymupdf) parses uploaded PDFs, extracting clean textual content while retaining 1-indexed source page metadata.

Step 2: Sliding Window Chunking

Text is partitioned into 500-character segments with a 100-character overlap to preserve semantic context across sentence boundaries.

Step 3: Dense Vector Similarity

Query and chunk embeddings are generated via all-MiniLM-L6-v2; cosine similarity retrieves the top-4 relevant passages.

RAG Grounding & Anti-Hallucination Guard

The language model is strictly bound to the retrieved context passages:

"Rule: If the provided notes do not contain enough facts to answer the question, state: 'The uploaded notes do not contain enough information to answer this question.'"

Output Verification: Answers cite specific source pages (e.g., [Source Page 2]), providing full academic auditability.

Speaker Notes: Our RAG pipeline prevents AI hallucinations. When a student queries their notes, PyMuPDF and Sentence Transformers isolate the most relevant text chunks. If the answer is absent from their notes, the model explicitly refuses to fabricate facts.

Module 4: AI Quiz Generator & Evaluation Hub

Automating diagnostic assessment and formative feedback for active recall.

Structured 4-Option MCQ Synthesis

Generates multiple-choice questions from any custom subject or uploaded PDF notes. Enforces exactly four distinct options (A, B, C, D) and a verified correct option.

Anti-Cheating Answer Separation

Correct answers are segregated on the server. The exam API returns only question texts and options, preventing inspect-element inspection during test attempts.

Instant Explanations & Retries

Submissions are auto-scored into percentage marks. Each incorrect choice includes an academic explanation explaining why the correct choice holds.

Speaker Notes: The Quiz Hub encourages active recall. We enforce a robust 4-choice JSON schema, hide correct answers during test execution to prevent cheating, and provide pedagogical explanations for every question upon completion.
